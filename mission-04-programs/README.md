### Task 4.2 - Compare compiler and interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation/execution happens| Translates entire code | Translates line by line|
| Typical output | Creates a separate executable or translated file | Does not create a separate executable or translated file|
| One example | C, C++ code | Python, Ruby|
| One advantage | Run quickly | Can detect errors easier |

Compiler debugs the entire code while interpreter does it line by line. So compiler runs faster than interpreter. But we can identify our errors easily in interpreter than compiler.

## 4. My understanding
The computer needs software to translate or carry out the instructions in a program. A compiler usually translates code before it runs, while an interpreter works through the instructions as the program runs.
